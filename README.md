# 手势太阳系 · 指尖漫游宇宙

一个用手势漫游的 3D 太阳系：太阳与八大行星使用真实天文贴图，带公转、自转、大气辉光与土星环阴影。
**双手张合缩放、挥手切换、握拳拖拽转视角、张掌回全景**，手划过星空会留下星尘，镜头平滑飞向目标并展示中文科普卡。

---

## 一、怎么启动

> **不要直接双击 `index.html`**。摄像头与 ES 模块在 `file://` 下会被浏览器拦截，必须通过本地服务访问。

### 方式一（推荐）：双击「启动.bat」

1. 双击项目里的 **`启动.bat`**，浏览器会自动打开。
2. 点击 **「点 击 进 入」** → 浏览器请求摄像头时点「允许」。
3. 关闭命令行窗口即可停止服务。

### 方式二：命令行

```bash
cd 项目目录
python serve.py 8200
```

打开 **http://localhost:8200**。`serve.py` 使用多线程与大连接队列，能稳定应对高清贴图和模型并发加载。

> **改代码后必须能立刻生效**：`serve.py` 对 `.html / .js / .css / .mjs` 一律返回 `no-store`，
> 只有贴图、模型、wasm 走长缓存。之前这些代码文件被错误地缓存了 24 小时，
> 导致改了页面但浏览器还在跑旧版，现已修正。如果仍看到旧界面，看进入页底部的
> **BUILD 标记**确认版本，必要时按 `Ctrl + Shift + R` 强制刷新。

## 二、怎么玩

| 操作 | 效果 |
| --- | --- |
| **双手入画，两手拉开 / 并拢** | 拉开拉近、并拢拉远，最接近手机双指缩放的直觉 |
| **单手上抬 / 下压** | 只识别到一只手时自动降级为推拉缩放，抬手拉近、下压拉远 |
| **手向左 / 向右挥** | 切换上一颗 / 下一颗星球，镜头飞过去 |
| **握拳后拖动** | 像抓着场景转：左右转方位、上下调俯仰 |
| **握拳静止约 0.8 秒** | 暂停 / 继续所有星体的公转与自转 |
| **张开手掌静止约 1 秒** | 返回太阳系全景（手掌在移动时不会误触发） |
| **手划过星空** | 拖出星尘尾迹，颜色跟随当前星球 |
| **鼠标点击星球** | 直接聚焦该星球 |
| **鼠标拖动 / 滚轮** | 环绕视角 / 缩放 |
| 右下角小窗 | 两只手的骨架、缩放条、停留动作进度反馈 |

> 缩放已从「拇指食指捏合」改为双手间距。原因是捏合距离在手掌侧向镜头时投影会急剧压缩，
> 而 z 轴深度估计抖动大，容易突跳；双手间距与手掌高度都是画面内可直接测量的量，稳定得多。
> 所有缩放都走相对增量，手入镜、静止或离场都不会让镜头跳动。

### 键盘降级（摄像头不可用时功能完整）

| 按键 | 作用 |
| --- | --- |
| `←` / `→` | 上一颗 / 下一颗星球 |
| `↑` / `↓` | 拉近 / 拉远 |
| `Home` 或 `0` | 太阳系全景 |
| `空格` | 暂停 / 继续星体运动 |
| `D` | 演示模式（隐藏全部 UI，适合录屏），`Esc` 退出 |

如果摄像头权限被拒绝，页面会给出中文重置指引与「重试摄像头」按钮，而不是静默失败。

## 三、画面与性能设计

- **远景轻量、特写高清**：所有天体首屏使用 2K 贴图，只有当前聚焦天体动态加载 4K 高清贴图；切换时释放上一张高清贴图，显存不会越用越多。
- **手势独立线程**：MediaPipe 推理运行在 Web Worker，使用 384×288 的 `ImageBitmap`，不阻塞 3D 主循环。
- **自适应画质**：持续低帧时依次降低渲染分辨率并关闭泛光；性能模式直接渲染，完全绕开 HDR 离屏缓冲与全屏输出 pass。
- **真实感细节**：4096×2048 高清地表、地球独立云层与夜面城市灯光、随日照变化的大气边缘辉光、土星环透光与行星投影遮蔽、ACES 色调映射与半分辨率 Bloom。
- **镜头约束**：聚焦行星时自动位于被太阳照亮的一侧，不会飞到夜面看见一颗全黑星球。
- **星尘是真 3D**：手的屏幕位置经相机射线映射成世界坐标，粒子在场景里飘散、受深度影响，而不是贴在屏幕上的 2D 特效；420 个粒子环形缓冲，代价可以忽略。

## 四、收录天体

太阳 · 水星 · 金星 · 地球（含月球、云层、夜间灯光）· 火星 · 木星 · 土星（含环）· 天王星 · 海王星

每颗星球配有真实数据（直径 / 距日 / 一天长度等）与一条中文趣闻。行星尺寸与轨道为艺术化压缩比例，资料数值为真实值。

## 五、目录说明

```
手势太阳系/
├── index.html / style.css          页面与视觉
├── js/
│   ├── data.js                     天体数据与手势参数
│   ├── scene.js                    3D 场景、动态贴图、画质控制
│   ├── gestures.js                 手势状态机
│   ├── gesture-worker.js           MediaPipe 推理 Worker
│   └── app.js                      页面、摄像头、UI 串联
├── assets/textures/                星球贴图（Solar System Scope，CC BY 4.0）
├── vendor/
│   ├── three/                      three.js r160 与后期处理模块
│   └── mediapipe/ + models/        手部识别 wasm 与模型
├── serve.py                        多线程本地静态服务
└── 启动.bat                         一键启动
```

全程离线可用，不依赖外部 CDN。
